## [Don't Classify, Hallucinate: Matching Imagined Tags with Embeddings](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/) ⭐️ 8.2/10

Simon Willison highlights a technique by Doug Turnbull for tagging untagged content: an LLM first generates hypothetical tags without seeing the existing vocabulary, then vector embeddings match those imagined tags to the closest real tags in the controlled vocabulary, avoiding the need to feed a massive tag list to the model. This matters because large controlled vocabularies (like Willison's 1,856 tags) are often too big for direct LLM classification, and this 'hallucinate then embed' approach offers a practical, token-efficient alternative. It can also improve semantic accuracy by decoupling generation from recognition. The example prompt shows the model a few tag shape examples such as 'Furniture / Living Room Furniture / Coffee Tables & End Tables / Coffee Tables' so its hallucinated tags are structurally similar. The subsequent embedding-based matching step maps the hallucinated tags onto the existing tag vocabulary.

rss · Simon Willison · Aug 14, 21:54

**Background**: Vector embeddings are numerical representations of words or sentences, where similar meanings are placed close together in a high-dimensional vector space, so similarity can be computed by vector distance. A controlled vocabulary is a predefined set of preferred terms used for indexing, like a taxonomy or tag list, which ensures consistency in retrieval. When a tag set is too large to include in a prompt, having the model hallucinate candidate tags first and then embedding-match them to the controlled vocabulary can save context window space and improve results.

Ruan's weekly reaches a large developer audience, making this topic highly relevant to the broader Chinese tech ecosystem. The issue explains how KV cache stores the key-value pairs computed in the attention mechanism to avoid redundant computation, and how semantic caching uses vector similarity to reuse LLM responses for similar prompts. It also covers the memory management challenges introduced by caching, such as quantization and sliding-window techniques.

rss · 阮一峰周刊 · Aug 13, 23:54

**Background**: Large language models generate text by predicting one token at a time, and each step attends to all previous tokens via the Transformer's attention mechanism. Semantic caching goes further by comparing the embedding vectors of prompts, so that similar user queries can be answered with a previously generated response.
